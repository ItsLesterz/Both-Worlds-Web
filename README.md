# Both Worlds Global - React + Bootstrap v3

This version is rebuilt to closely match the approved screenshots:
- Same minimal white/soft-gray visual style
- Hero with globe/orbits and three value blocks
- About section with visual panel
- Six service cards
- Why Both Worlds 2x2 layout
- How It Works with 4-step process
- Dark navy CTA
- Contact layout with left-side details and right-side form

## Install
```bash
npm install
```

## Run
```bash
npm start
```

or
```bash
npm run dev
```

Vite normally opens at:
http://localhost:5173

## Main edit points
- Contact email/phone: `src/components/Contact.jsx`
- Brand copy: individual files in `src/components/`
- Colors and spacing: `src/styles/main.css`
- Logos: `public/images/`

The contact form is frontend-only for now.
